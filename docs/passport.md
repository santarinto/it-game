# Паспорт проекта: IT Director Web Game

Обновлён: 2026-07-18.

## Что это

Браузерный кликер про развитие IT-компании — форк идеи старой web-игры
Intel «IT Manager 3: Unseen Forces» в pixel style. Игрок покупает ПК,
нанимает сотрудников, строит сеть (роутеры → стойка роутеров/core →
серверные стойки → шлюз в интернет), открывает офисы и балансирует
доход против ФОТ и опекса. Проигрыш — банкротство на вечернем расчёте.

- **Прод:** https://itgame.santarinto.ru (сервер `site`, 217.197.115.128)
- **Репозиторий:** https://gitflic.ru/project/santarinto-labs/it-director-web-game
- **Старт разработки:** 2026-07-11

## Стек и архитектура

- **Сервер:** Go (актор-модель: на каждое WebSocket-подключение своя
  игра и горутина, тик = 1 реальная секунда на скорости 1x). Без
  сохранений: разрыв соединения = новая игра.
- **Клиент:** Phaser 3 + TypeScript + Vite; весь пиксель-арт
  кодогенерируется (`client/src/pixelart.ts`), внешних ассетов нет.
- **Протокол:** JSON поверх WS; `client/src/protocol.ts` — ручное
  зеркало `server/internal/ws/protocol.go`, меняются синхронно.
- **БД:** PostgreSQL, опциональна (геймплей не зависит; каталог
  оборудования для `/admin`). Миграции — самописные, по имени файла.

## Прод и CI/CD

- CD: пуш в `main` → GitFlic CI (Go vet/test + typecheck/build клиента)
  → on-box webhook (HMAC) → атомарный релиз
  (`releases/<id>` → своп симлинка `current` → `systemctl restart itgame`).
- Схема и грабли GitFlic — плейбук `gitflic-ci-cd-playbook.md` (репо
  my-santarinto); детали игры — раздел «Прод» в README.
- `/admin` на проде закрыт basic auth (доступы — вне репозитория).
- Деплой рвёт активные WS-сессии — до итерации с аккаунтами/сейвами
  это принятая цена.
- IPv6 у хостера не маршрутизируется (тикет в ESTT открыт 2026-07-18);
  прод — только IPv4/A-запись.

## Процесс разработки

Рабочий цикл итерации: **брейншторм → спека → план → SDD
(subagent-driven development) → браузерный смоук → финальное ревью →
плейтест пользователя → мерж в main** (мерж только после плейтеста;
с итерации 7 мерж в main автоматически деплоится на прод).

- Геймдизайн (живой документ): `docs/design/gdd.md`
- Спеки: `docs/superpowers/specs/`
- Планы реализации: `docs/superpowers/plans/`
- Журнал выполнения (ledger, git-ignored): `.superpowers/sdd/progress.md`
- **Вехи развития: `docs/stages/`** — по файлу на этап, с итогами
  плейтестов и ключевыми решениями.

## Текущее состояние (2026-07-18)

Итерация 7 в проде. Эндгейм-баланс: 3 офиса × 12 сотрудников, 9
серверных стоек ур.3, стойка роутеров ур.5 (36/36 мест), шлюз;
максимальный множитель ×2.64. Следующая большая тема — аккаунты и
сейвы (session-token + PostgreSQL + restore при реконнекте).
