## Что построено

  сервер работает как раньше.
- Служебная страница `/admin`: баланс игры из `config.go` + каталог
  из БД; ссылка «Админка» в DOM-шапке.
- Быт-устройства на полке офиса: кулер ($400, снимает дебафф жажды
  −10% с 12:00), холодильник ($600, голод −10% после обеда),
  кофеварка ($800, бафф +15% на час, 40% на сотрудника дважды в
  день). Дебаффы стакаются мультипликативно, эффекты — в тултипе.

## Ключевые решения и уроки плейтеста

- Эффекты считает сервер; сид-тесты для случайного кофе (стабильны
  20 прогонов).
- Баг плейтеста №1: `effects:null` в JSON обрывал перерисовку офиса —
  теперь массивы в снапшоте никогда не `null` (регрессионный тест;
  правило вошло в Global Constraints последующих планов).
- Баг плейтеста №2: тултип показывал базовую выработку без дебаффов —
  сервер отдаёт `effectiveIncomePerTick`, клиент показывает
  эффективную с базой в скобках.
- Заявки плейтеста → итерация 6: пауза/скорость, debug-режим.
