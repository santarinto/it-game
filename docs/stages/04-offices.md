# Этап 4 — Три офиса, начальники, шлюз (итерация 4)

Дата: 2026-07-12. Ветка `iteration-4`, 12 коммитов
(`0db0ac9…3d5c43d` + фиксы `a8979f3`, `6cf144f`). Плейтест: пройден
(«офис 2 — большое решение, шлюз заметен, середина не проседает»);
по итогам — заявки, ставшие итерацией 5.

## Что построено

- Компания вширь: офисы 2 ($15,000) и 3 ($40,000), открываются
  пустыми; у каждого офиса свой роутер и свой начальник ($1,000 +
  $500/день, открывает места 10–12).
- Шлюз в интернет на компанию ($3,000 + $1/день опекса): ×1.2 к
  доходу от серверов во всех подключённых офисах.
- Панель навигации слева (О1/О2/О3/СРВ), сцена серверной отдельно.
- Строка «Расходы» в HUD (ФОТ + опекс); неполный день: нанятый после
  15:00 зарплату за день найма не получает.
- Протокол переехал на массив офисов с адресацией команд.

## Ключевые решения

- Имплементатор поймал баг плана (порядок проверок BuyPC) — ревью
  сабагентов ловит и ошибки контроллера, не только исполнителя.
- Утечка объектов (пол серверной перерисовывался каждый тик)
  найдена контроллером на смоуке — рендер статики только в create().
- Роутер тир 3 добавлен пост-плейтестным фиксом: офис с начальником
  (12 мест) должен подключаться целиком.
