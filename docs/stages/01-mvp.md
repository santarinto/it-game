# Этап 1 — MVP: кликер с сетью (итерация 1)

Даты: 2026-07-11 → 2026-07-12. Ветка `iteration-1-mvp`, 14 коммитов
(`2d40ce9…4c8a6c9`). Плейтест: пройден.

## Что построено

Игра с нуля: Go-сервер (актор на WS-подключение, тик 1 с) + клиент
Phaser 3/TS/Vite с кодогенерируемым пиксель-артом.

- Экономика в USD: покупка ПК ($500), найм ($300), доход $/тик.
- Сеть-мультипликатор: роутер (3 тира, порты) и общий сервер —
  сотрудники «в сети» приносят больше.
- Слот роутера — специальный, не взаимозаменяем с рабочими местами.
- WS-протокол: снапшот состояния на каждый тик, команды покупок,
  коды ошибок; клиент — тонкий рендерер снапшотов.

## Ключевые решения

- Актор-модель вместо мьютексов: одна горутина владеет `*game.Game`,
  весь мир общается через канал команд — гонок нет по построению.
- Живая проверка протокола без браузера (`scripts/live-check.mjs`) —
  реальный WS-клиент на Node, критерий «ПРОТОКОЛ ОК».
- Пиксель-арт кодогеном: 4 CC0-пака Kenney не дали офисной семантики,
  рисование своих текстур из палитры оказалось быстрее и гибче.
