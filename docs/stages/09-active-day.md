## Что построено

- **Мотивация кликом:** клик по сотруднику — бафф «мотивирован» +25%
  на 18 тиков, персональный кулдаун 36; жёлтый бейдж и строка в тултипе.
- **Инциденты-поломки:** 2%/тик на офис, максимум один сломанный ПК
  на офис; доход места 0; чинится 3 кликами по столу или мастером $150;
  ночной сброс.
- **Отчёт дня:** incidents + lostIncome; прогноз конца дня считает
  сломанный ПК сломанным до починки (консервативно).
- Протокол: `motivate`/`repair_click`/`call_master`, поля
  `pcBroken`/`repairClicks`/`motivateReadyAt`, `prices.repair`;
  protocol.ts зеркально.

## Ключевые решения

- Клик-механика вместо денег: «событие → решение игрока» без третьего
  вида трат; экономика — +$52/клик среднему сотруднику, клики выгоднее
  мастера (это осознанная «скилловая» награда).
- Поломка роллится на любом тике, включая обед — безвредно: доход там 0.
- Твины мигания поломок убиваются `killTweensOf` при полной перерисовке
  сцены, иначе утечка анимаций.
- Live-проверка детерминированной части + Go-тесты со 100% шансом
  поломки вместо ожидания роллов в live.
