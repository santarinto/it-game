# Этап 2 — Зарплаты и цикл дня (итерация 2)

Дата: 2026-07-12. Ветка `iteration-2`, 14 коммитов
(`5e2970e…336deea` + фикс `ea2cd45`). Плейтест: пройден
(критерий «≥1 решение "инфраструктура вместо найма", ≥1 момент
риска банкротства» — сработал).

## Что построено

- Цикл дня: день → вечерний расчёт (доход, ФОТ $250/сотрудник,
  прибыль, баланс) → модалка отчёта с паузой → следующий день.
- Банкротство: не хватило на полный ФОТ — game over с итогами
  (дней прожито, пиковый доход) и рестартом.
- Галка «пропускать отчёты», прогноз конца дня в HUD (красный при
  ожидаемом минусе), форматирование денег с тысячами.
- Фазы игры на сервере (`running`/`day_report`/`game_over`) с
  гейтингом команд по фазе.

## Ключевые решения

- Тикер молчит на паузе отчёта (фикс финального ревью) — снапшоты
  не летят каждую секунду, пока игрок читает отчёт.
- Закрытый union типов сообщений на клиенте с жёстким матчингом.
- Браузерный смоук контроллером через Playwright стал штатной частью
  итерации (canvas-рендер скриншотами).
