# IT Director — геймдизайн-документ (живой)

Обновлён: 2026-07-11 (итерация 1 — MVP)

Это живой документ. Перед каждой итерацией сначала правим его, потом код.
Числа баланса здесь — источник истины для конфига сервера
(`server/internal/game` — конфиг баланса); при изменении обновлять оба места.

## Видение

Форк «IT Manager 3: Unseen Forces» (Intel) в pixel style.
Игрок — IT-директор: развивает компанию, покупая технику и нанимая людей.
Весь интерфейс крутится вокруг комнат — сначала офис и серверная,
позже возможны новые. Жанр — кликер/менеджер в реальном времени.

Референсы: оригинальная игра (itmanager3.intel.com, закрыта),
статья Matthew Mayes, видеоинтервью разработчика.

## Комнаты

### Офис
- 9 слотов под рабочие места.
- Слот: пустой → стол с ПК → стол с ПК и сотрудником.
- Здесь происходит покупка ПК и найм.

### Серверная
- 3 слота под серверные стойки.
- Каждый сервер расширяет ёмкость рабочих мест.

## Ядро цикла (итерация 1)

```
деньги → купить ПК → нанять сотрудника → доход за тик → деньги
                     ↑
       свыше 3 сотрудников — нужны серверы (серверная)
```

Стадии роста:

1. **Малый офис (1–3 сотрудника).** Серверы не нужны: базовая ёмкость 3
   («роутер под столом»). Игрок осваивает покупку ПК и найм.
2. **Порог роста.** Найм 4-го блокируется с подсказкой «Нужен сервер» —
   игра сама ведёт игрока в серверную.
3. **Серверная (4–9 сотрудников).** Сервер даёт +3 места. Потолок MVP —
   9 сотрудников (3 базовых места + 2 сервера; третья стойка — запас на рост).

## Экономика (итерация 1)

| Параметр            | Значение | Комментарий                                  |
|---------------------|----------|----------------------------------------------|
| Старт: деньги       | $600     | хватает на первый найм сразу ($300)          |
| Старт: ПК           | 1        | первое действие очевидно — «Нанять»          |
| Цена ПК             | $500     |                                              |
| Цена найма          | $300     | разовая, зарплат в MVP нет                   |
| Цена сервера        | $2000    | заметное накопление перед стадией 2          |
| Доход за тик        | $10/сек с сотрудника |                                  |
| Базовая ёмкость     | 3 места  | без серверов                                 |
| Ёмкость сервера     | +3 места |                                              |

Окупаемость: найм — 30 сек; связка ПК+найм — 80 сек; сервер при 3 работающих
сотрудниках копится ~67 сек. Полный прогон до 9 сотрудников — ориентировочно
15–20 минут спокойной игры. Числа стартовые — крутим по плейтесту.

## Плейтест

В конце каждой итерации играем сами и записываем сюда: что скучно,
что непонятно, где провис темпа. Записи — вход следующей итерации.

## Бэклог идей (не в MVP)

Из оригинала и своих:

- Поломки ПК/серверов и ремонт кликом (сотрудник простаивает — «кликерность»).
- Оффлайн-прогресс (симуляция догоняется при входе).
- Апгрейд/переезд офиса — больше слотов.
- Типы сотрудников (разработчик, админ, хелпдеск) и их прокачка.
- Апгрейды техники (ПК быстрее → доход выше; серверы мощнее).
- Случайные события (вирусы, дедлайны, аудит) — «Unseen Forces».
- Задания/миссии от бизнеса, репутация.
- Персистентность (PostgreSQL), аккаунты, лидерборды.
- Звук, музыка, анимации персонажей.
