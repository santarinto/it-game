# IT Director — геймдизайн-документ (живой)

Обновлён: 2026-07-11 (итерация 1 — MVP)

Это живой документ. Перед каждой итерацией сначала правим его, потом код.
Числа баланса здесь — источник истины для конфига сервера
(`server/internal/game` — конфиг баланса); при изменении обновлять оба места.

## Видение

Форк «IT Manager 3: Unseen Forces» (Intel) в pixel style.
Игрок — IT-директор: развивает компанию, покупая технику и нанимая людей.
Весь интерфейс крутится вокруг комнат — сначала офис и серверная,
позже возможны новые. Жанр — кликер/менеджер в реальном времени.

Референсы: оригинальная игра (itmanager3.intel.com, закрыта),
статья Matthew Mayes, видеоинтервью разработчика.

## Валюта и работа

Базовая валюта игры — **доллар США ($)**.

Единица производства — **единица работы**: одно рабочее место (сотрудник за ПК)
без сети производит 1 базовую единицу работы. Объём работы измеряется за
рабочий (8-часовой) день; в итерации 1 цикла «день» в коде нет — работа
конвертируется в доллары каждый тик, а «день» остаётся расчётной единицей GDD.
Механика дня (зарплаты, дневные события) — в бэклоге.

## Комнаты

### Офис
- 9 слотов под рабочие места + один **специальный слот под роутер**:
  рабочее место в него поставить нельзя, а роутер нельзя поставить
  в обычный слот. Типы слотов не взаимозаменяемы.
- Слот рабочего места: пустой → стол с ПК → стол с ПК и сотрудником.
- Здесь происходит покупка ПК, найм и установка/апгрейд роутера.
- **Роутер — сетевая инфраструктура офиса**: у каждого офиса свой роутер,
  число его портов определяет, сколько рабочих мест подключено к сети.
  На старте роутера нет — его надо купить.

### Серверная
- 3 слота под серверные стойки.
- **Сервер — мультипликатор**: увеличивает объём работы, который подключённые
  к сети рабочие места производят за рабочий день. Без сети (роутера)
  серверы не дают ничего.

## Ядро цикла (итерация 1)

```
деньги → купить ПК → нанять → единицы работы → $ за тик → деньги
                                   ↑
              роутер (сеть) → серверы (мультипликатор подключённым)
```

Стадии роста:

1. **Без сети.** Старт: 1 ПК, ни роутера, ни серверов. Игрок нанимает,
   докупает ПК — линейный рост на базовой выработке.
2. **Сеть.** Покупка роутера: подключённые рабочие места получают ×1.5.
   Портов у базового роутера 4 — часть офиса остаётся вне сети.
3. **Серверная.** Каждый сервер +0.5× подключённым. Апгрейд роутера до
   офисного (9 портов) подключает весь офис. Потолок MVP: 9 сотрудников
   на ×3.0.

Подключение к сети автоматическое: первые N занятых рабочих мест
(N = порты роутера), без микроменеджмента.

## Экономика (итерация 1)

Формула дохода за тик:
`Σ по сотрудникам: базовая_выработка × (подключён_к_сети ? сетевой_множитель : 1)`,
где `сетевой_множитель = 1.5 + 0.5 × число_серверов` (максимум ×3.0).

| Параметр                  | Значение | Комментарий                              |
|---------------------------|----------|------------------------------------------|
| Старт: деньги             | $600     | хватает на первый найм сразу ($300)      |
| Старт: ПК                 | 1        | роутера и серверов на старте нет         |
| Цена ПК                   | $500     |                                          |
| Цена найма                | $300     | разовая, зарплат в MVP нет               |
| Базовая выработка         | 1 ед. работы/тик = $10/тик |                        |
| Роутер базовый (тир 1)    | $800     | 4 порта, подключённым ×1.5               |
| Роутер офисный (тир 2)    | $2500    | 9 портов (замена тира 1)                 |
| Сервер                    | $2000    | +0.5× подключённым, до 3 серверов        |

Максимальный доход MVP: 9 сотрудников × $10 × 3.0 = $270/тик.
Окупаемость: найм — 30 сек; ПК+найм — 80 сек; роутер при 3 сотрудниках
окупается за ~53 сек ($15/тик прибавки). Полный прогон до потолка —
ориентировочно 20–25 минут. Числа стартовые — крутим по плейтесту.

## Бэклог идей (не в MVP)

Из оригинала и своих:

- Цикл рабочего дня (8 часов): зарплаты по дням, дневные события, отчёты.
- Работа как отдельный ресурс/валюта (контракты: продавать единицы работы).
- Поломки ПК/серверов и ремонт кликом (сотрудник простаивает — «кликерность»).
- Оффлайн-прогресс (симуляция догоняется при входе).
- Апгрейд/переезд офиса — больше слотов; у каждого офиса свой роутер.
- Типы сотрудников (разработчик, админ, хелпдеск) и их прокачка.
- Апгрейды техники (ПК быстрее → доход выше; серверы мощнее).
- Случайные события (вирусы, дедлайны, аудит) — «Unseen Forces».
- Задания/миссии от бизнеса, репутация.
- Персистентность (PostgreSQL), аккаунты, лидерборды.
- Звук, музыка, анимации персонажей.
