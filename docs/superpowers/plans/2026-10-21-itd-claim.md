# `itd.claim` — the agent's tab bar and press counter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `itd.claim(label)` puts a visible «▶ АГЕНТ работает в этой вкладке — не кликай» bar on the browser agent's tab and counts every real press in it as the agent's own (`mine()`), the human's allowed («нажми сам», `allow(what, {target})`, scored by Phaser's `got`) or foreign; the state survives F5 and `itd.reset()`. Spec: `docs/superpowers/specs/2026-10-21-itd-claim-design.md`, tracker ITGAME-151, design approved by the owner on 21.10.2026.

**Architecture:** Pure counting logic lives in `client/src/debug/claimCore.ts` (no Phaser, no DOM, unit-tested in Node). `client/src/debug/claim.ts` adds the DOM bar, the window capture listeners, sessionStorage and the Phaser `got` probe, and builds `ClaimApi` as a callable with methods, like `sandbox.ts`. The `got` listener mechanics move out of `itd.trace` into a shared `makeGotCatcher()` in `trace.ts`. `agentApi.ts` wires `claim` into `ItdApi`, help and the contract, and restores a saved claim at install time, before Phaser `READY`.

**Tech Stack:** TypeScript client (Vite, Phaser 3.90); Node 26 `node --test` running `.ts` sources directly (type stripping: no enums, no parameter properties); puppeteer-core QA scripts against a self-served Go server (`client/scripts/lib/selfserve.mjs`).

## Global Constraints

- `itd.claim` exists only where `itd` is installed (dev build, `?debug=1`, `localStorage itd.debug = '1'`).
- Bar: `div#itd-claim`, `data-mode` = `claim` | `allow` | `foreign`, `position: fixed; top: 0; left: 0; right: 0; height: 40px; z-index: 100000; pointer-events: none`, bold 20px monospace, centered. Colors: claim `#f5c542`, allow `#51cf66`, foreign flash `#ff6b6b` for 600 ms.
- Bar text: `▶ АГЕНТ работает в этой вкладке (<label>, <sha>) — не кликай`; allow: `▶ ТВОЙ ХОД: <what> — только это`.
- Tab title: `▶ АГЕНТ — смотри, не кликай` while claimed; `вкладка свободна` after `stop()`.
- Presses: window capture listeners on `pointerdown` and `mousedown`; events within 50 ms of a group's first event are one press; `isTrusted === false` only increments `synthetic`; a `mousedown` with `sourceCapabilities.firesTouchEvents` is ignored.
- Classification order: pending, unexpired `mine` budget → `own`; open allow window → `allowed`; otherwise `foreign` (red flash).
- Limits: `label` non-empty, ≤ 40 chars; `what` non-empty, ≤ 80 chars; `mine(n = 1, ms = 20000)`, `n` integer 1..20, `ms` integer 100..120000; `presses` keeps the last 50.
- Refusal codes: `bad_label`, `bad_args`, `no_claim`, `no_allow`; shape `{ok: false, code, error}` with a Russian `error` text.
- sessionStorage key `itd.claim`, through `sessionStore` (`client/src/storage.ts`); rewritten after every change and on `pagehide`.
- Comments and user-facing texts are in Russian, matching the surrounding code. Commits follow the house style (`feat(client): … — ITGAME-151`) and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- QA port for the new script: `:4198` (4173–4197 are taken by other scripts).

```ts
// itd.claim (ITGAME-151): чистая логика полосы «АГЕНТ работает в этой вкладке» — счёт
// нажатий own/allowed/foreign, бюджет mine, окно allow, запись для sessionStorage.
// Без Phaser и DOM: scripts/lib/claim.test.mjs гоняет её прямо в Node (type stripping —
// ни enum, ни parameter properties). DOM-часть — claim.ts.

export const CLAIM_KEY = 'itd.claim'
export const GROUP_MS = 50 // события одного нажатия (pointerdown → mousedown) — одна группа
export const PRESS_CAP = 50 // presses хранит последние 50 нажатий
export const LABEL_MAX = 40
export const WHAT_MAX = 80
export const MINE_MAX_N = 20
export const MINE_MIN_MS = 100
export const MINE_MAX_MS = 120_000
export const MINE_DEFAULT_MS = 20_000

export type ClaimKind = 'own' | 'allowed' | 'foreign'

export interface ClaimPress {
  /** Номер нажатия с claim(): общий счёт own, allowed и foreign. */
  n: number
  /** Секунды от claim(), одна десятая. */
  t: number
  /** own — после itd.claim.mine(), allowed — в окне allow, foreign — чужое. */
  kind: ClaimKind
  button: number
  /** Нажатие пришло в холст игры; false — мимо (#topbar, поля страницы). */
  onCanvas: boolean
  /** Победитель хит-теста Phaser в момент нажатия — метка, как pointer.wins в itd.trace (safe id или тип); null — мимо интерактивов. */
  wins: string | null
  /** Кому Phaser отдал нажатие (GAMEOBJECT_POINTER_DOWN), как pointer.got в itd.trace. */
  got: string[]
}

export interface ClaimAllowWindow {
  what: string
  /** id цели в safe-форме (с «:»), null — без цели. */
  target: string | null
  /** Секунды от claim() до allow(). */
  since: number
  /** Окну принадлежат нажатия с n > from. */
  from: number
}

export interface ClaimRecord {
  label: string
  sha: string
  at: number // Date.now() при claim()
  own: number
  allowed: number
  foreign: number
  synthetic: number
  onCanvas: number
  reloads: number
  mine: { pending: number; until: number } | null // until — Date.now()
  allow: ClaimAllowWindow | null
  presses: ClaimPress[]
}

export interface ClaimState {
  ok: true
  /** Полоса стоит; в итоге stop() — false. */
  active: boolean
  label: string
  /** itd.version.sha вкладки. */
  sha: string
  /** Секунды от claim(). */
  sec: number
  /** Настоящие нажатия: own + allowed + foreign. */
  downs: number
  own: number
  allowed: number
  foreign: number
  /** isTrusted false (dispatchEvent, itd.tap) — в downs не входят. */
  synthetic: number
  onCanvas: number
  /** Сколько перезагрузок вкладки claim пережил. */
  reloads: number
  /** Бюджет itd.claim.mine(): сколько ещё нажатий — own и сколько мс он жив; null — нет. */
  mine: { pending: number; leftMs: number } | null
  /** Открытое окно allow; hit — target в got разрешённого нажатия окна (null без target). */
  allow: (ClaimAllowWindow & { hit: boolean | null }) | null
  /** Последние 50 нажатий, старые первыми. */
  presses: ClaimPress[]
}

export interface ClaimAllowResult {
  ok: true
  what: string
  target: string | null
  /** Разрешённые нажатия этого окна. */
  presses: ClaimPress[]
  /** target в got хотя бы одного из них; null — окно без target. */
  hit: boolean | null
}

export interface ClaimRefusal {
  ok: false
  code: 'bad_label' | 'bad_args' | 'no_claim' | 'no_allow'
  error: string
}

export function refuse(code: ClaimRefusal['code'], error: string): ClaimRefusal {
  return { ok: false, code, error }
}

export function newRecord(label: string, sha: string, now: number): ClaimRecord {
  return {
    label, sha, at: now, own: 0, allowed: 0, foreign: 0, synthetic: 0, onCanvas: 0, reloads: 0,
    mine: null, allow: null, presses: [],
  }
}

const filled = (s: unknown, max: number): boolean => typeof s === 'string' && s.trim() !== '' && s.length <= max

export function checkLabel(label: unknown): ClaimRefusal | null {
  return filled(label, LABEL_MAX) ? null : refuse('bad_label', `метка — непустая строка до ${LABEL_MAX} символов`)
}

const intIn = (v: unknown, lo: number, hi: number): boolean => Number.isInteger(v) && (v as number) >= lo && (v as number) <= hi

export function checkMine(n: unknown, ms: unknown): ClaimRefusal | null {
  return intIn(n, 1, MINE_MAX_N) && intIn(ms, MINE_MIN_MS, MINE_MAX_MS)
    ? null
    : refuse('bad_args', `mine(n, ms): n — целое 1..${MINE_MAX_N}, ms — целое ${MINE_MIN_MS}..${MINE_MAX_MS}`)
}

export function checkAllow(what: unknown, target: unknown): ClaimRefusal | null {
  if (!filled(what, WHAT_MAX)) return refuse('bad_args', `allow(что, {target?}): что — непустая строка до ${WHAT_MAX} символов`)
  if (target !== undefined && (typeof target !== 'string' || target === '')) {
    return refuse('bad_args', 'allow: target — id объекта (btn.hire или btn:hire)')
  }
  return null
}

// safe-форма id, как у got/wins трассы: «:» вместо точек (в id игры двоеточий нет).
export const normTarget = (id: string): string => id.replace(/\./g, ':')

export const downsOf = (rec: ClaimRecord): number => rec.own + rec.allowed + rec.foreign

const tenths = (ms: number): number => Math.round(ms / 100) / 10

export function liveMine(rec: ClaimRecord, now: number): ClaimRecord['mine'] {
  return rec.mine && rec.mine.pending > 0 && now < rec.mine.until ? rec.mine : null
}

// Новый вызов заменяет бюджет, а не прибавляет.
export function setMine(rec: ClaimRecord, n: number, ms: number, now: number): void {
  rec.mine = { pending: n, until: now + ms }
}

// Нажатие: own — пока жив бюджет mine, allowed — пока открыт allow, иначе foreign.
// Возвращает объект из rec.presses: wins/got вызывающий дописывает в него же.
export function addPress(rec: ClaimRecord, now: number, input: { button: number; onCanvas: boolean }): ClaimPress {
  let kind: ClaimKind
  const mine = liveMine(rec, now)
  if (mine) {
    kind = 'own'
    mine.pending -= 1
    rec.mine = mine.pending > 0 ? mine : null
  } else {
    rec.mine = null
    kind = rec.allow ? 'allowed' : 'foreign'
  }
  rec[kind] += 1
  if (input.onCanvas) rec.onCanvas += 1
  const press: ClaimPress = {
    n: downsOf(rec), t: tenths(now - rec.at), kind, button: input.button, onCanvas: input.onCanvas, wins: null, got: [],
  }
  rec.presses.push(press)
  if (rec.presses.length > PRESS_CAP) rec.presses.splice(0, rec.presses.length - PRESS_CAP)
  return press
}

// Новое окно заменяет открытое: его нажатия остаются в presses, но в новое не входят.
export function openAllow(rec: ClaimRecord, what: string, target: string | undefined, now: number): void {
  rec.allow = { what, target: target === undefined ? null : normTarget(target), since: tenths(now - rec.at), from: downsOf(rec) }
}

export function allowPresses(rec: ClaimRecord): ClaimPress[] {
  const w = rec.allow
  return w ? rec.presses.filter((p) => p.kind === 'allowed' && p.n > w.from) : []
}

export function allowHit(rec: ClaimRecord): boolean | null {
  const w = rec.allow
  if (!w || w.target === null) return null
  const target = w.target
  return allowPresses(rec).some((p) => p.got.includes(target))
}

const copyPress = (p: ClaimPress): ClaimPress => ({ ...p, got: [...p.got] })

export function closeAllow(rec: ClaimRecord): ClaimAllowResult | ClaimRefusal {
  const w = rec.allow
  if (!w) return refuse('no_allow', 'окна allow нет — itd.claim.allow(что, {target?})')
  const res: ClaimAllowResult = { ok: true, what: w.what, target: w.target, presses: allowPresses(rec).map(copyPress), hit: allowHit(rec) }
  rec.allow = null
  return res
}

export function stateOf(rec: ClaimRecord, now: number, active: boolean): ClaimState {
  const mine = liveMine(rec, now)
  return {
    ok: true, active, label: rec.label, sha: rec.sha, sec: Math.round((now - rec.at) / 1000), downs: downsOf(rec),
    own: rec.own, allowed: rec.allowed, foreign: rec.foreign, synthetic: rec.synthetic, onCanvas: rec.onCanvas,
    reloads: rec.reloads,
    mine: mine ? { pending: mine.pending, leftMs: mine.until - now } : null,
    allow: rec.allow ? { ...rec.allow, hit: allowHit(rec) } : null,
    presses: rec.presses.map(copyPress),
  }
}

// groupAt — performance.now() первого события группы; null — групп ещё не было.
export const joinsGroup = (groupAt: number | null, now: number): boolean => groupAt !== null && now - groupAt < GROUP_MS

export const serialize = (rec: ClaimRecord): string => JSON.stringify(rec)

const COUNTERS = ['at', 'own', 'allowed', 'foreign', 'synthetic', 'onCanvas', 'reloads'] as const

export function parseRecord(raw: string | null): ClaimRecord | null {
  if (raw === null) return null
  try {
    const r = JSON.parse(raw) as Partial<ClaimRecord> | null
    if (!r || typeof r.label !== 'string' || typeof r.sha !== 'string' || !Array.isArray(r.presses)) return null
    if (!COUNTERS.every((k) => Number.isFinite(r[k]))) return null
    return { ...(r as ClaimRecord), mine: r.mine ?? null, allow: r.allow ?? null }
  } catch {
    return null
  }
}
```

```ts
// под точкой ДО Phaser (capture-слушатель окна), снимаются, когда Phaser разослал событие:
// следующим arm()/flush() или setTimeout 0 — страховка, если следующего события не будет.
// Общие для itd.trace и itd.claim.
export interface GotCatcher {
  arm: (objs: Phaser.GameObjects.GameObject[], down: boolean, onGot: (label: string, obj: Phaser.GameObjects.GameObject) => void) => void
  flush: () => void
}

export function makeGotCatcher(): GotCatcher {
  let pending: (() => void)[] = []
  const flush = () => {
    const fs = pending
    pending = []
    fs.forEach((f) => f())
  }
  const arm: GotCatcher['arm'] = (objs, down, onGot) => {
    flush()
    const evName = down ? Phaser.Input.Events.GAMEOBJECT_POINTER_DOWN : Phaser.Input.Events.GAMEOBJECT_POINTER_UP
    for (const obj of objs) {
      // имя читаем сейчас: после destroy() в обработчике getData/type уже пусты
      const label = labelOf(obj)
      const on = () => onGot(label, obj)
      obj.on(evName, on)
      pending.push(() => obj.off(evName, on))
    }
    setTimeout(flush, 0)
  }
  return { arm, flush }
}
```

```ts
  deny: () => ClaimAllowResult | ClaimRefusal
  /** Счёт на сейчас; без полосы — {ok: true, active: false}. */

  /** Снять полосу и слушатели, стереть sessionStorage itd.claim, заголовок «вкладка свободна» → итог (active: false); отказ no_claim. */
  stop: () => ClaimState | ClaimRefusal
}

type TouchAware = MouseEvent & { sourceCapabilities?: { firesTouchEvents?: boolean } | null }

export function makeClaim(game: Phaser.Game, probe: PointerProbe, sha: string): ClaimApi {
  let rec: ClaimRecord | null = null
  let bar: HTMLDivElement | null = null
  let flashTimer: ReturnType<typeof setTimeout> | null = null
  let groupAt: number | null = null // performance.now() первого события текущего нажатия
  let synthAt: number | null = null // то же для синтетики
  const got = makeGotCatcher()

  const save = () => {
    if (rec) sessionStore.set(CLAIM_KEY, serialize(rec))
  }

  const paint = () => {
    if (!rec || !bar) return
    const mode = flashTimer !== null ? 'foreign' : rec.allow ? 'allow' : 'claim'
    bar.dataset.mode = mode
    bar.textContent = rec.allow
      ? `▶ ТВОЙ ХОД: ${rec.allow.what} — только это`
      : `▶ АГЕНТ работает в этой вкладке (${rec.label}, ${rec.sha}) — не кликай`
    bar.style.background = mode === 'foreign' ? COLOR_FOREIGN : mode === 'allow' ? COLOR_ALLOW : COLOR_CLAIM
  }

  const flash = () => {
    if (flashTimer !== null) clearTimeout(flashTimer)
    flashTimer = setTimeout(() => {
      flashTimer = null
      paint()
    }, FLASH_MS)
    paint()
  }

  const onDown = (ev: MouseEvent) => {
    const r = rec
    if (!r) return
    const now = performance.now()
    if (!ev.isTrusted) {
      if (!joinsGroup(synthAt, now)) {
        synthAt = now
        r.synthetic += 1
        save()
      }
      return
    }
    // Совместимый mousedown после касания: нажатие уже посчитал его pointerdown
    if (ev.type === 'mousedown' && (ev as TouchAware).sourceCapabilities?.firesTouchEvents) return
    if (joinsGroup(groupAt, now)) return
    groupAt = now
    const press = addPress(r, Date.now(), { button: ev.button, onCanvas: ev.target === game.canvas })
    if (press.kind === 'foreign') flash()
    try {
      const hit = probe(ev)
      press.wins = hit.wins ? (hit.wins.safe ?? hit.wins.type) : null
      // got: mousedown/touchstart этого нажатия браузер шлёт в той же задаче, Phaser отдаёт его объектам
      got.arm(hit.objs, true, (label) => {
        press.got.push(label)
        save()
      })
    } catch (e) {
      console.error('[claim] pointer probe упал:', e)
    }
    save()
  }

  const install = () => {
    if (!bar) {
      bar = document.createElement('div')
      bar.id = BAR_ID
      Object.assign(bar.style, {
        position: 'fixed', left: '0', right: '0', top: '0', height: '40px', zIndex: '100000',
        color: '#14162b', font: 'bold 20px/40px monospace', textAlign: 'center', pointerEvents: 'none',
        whiteSpace: 'nowrap', overflow: 'hidden', textOverflow: 'ellipsis',
      })
      document.body.appendChild(bar)
    }
    paint()
    document.title = TITLE_BUSY
    window.addEventListener('pointerdown', onDown, true)
    window.addEventListener('mousedown', onDown, true)
    // itd.reset() сносит все itd.* — активная полоса пишет себя снова перед уходом страницы
    window.addEventListener('pagehide', save)
  }

  const uninstall = () => {
    window.removeEventListener('pointerdown', onDown, true)
    window.removeEventListener('mousedown', onDown, true)
    window.removeEventListener('pagehide', save)
    got.flush()
    if (flashTimer !== null) clearTimeout(flashTimer)
    flashTimer = null
    bar?.remove()
    bar = null
    groupAt = null
    synthAt = null
  }

  const noClaim = (): ClaimRefusal => refuse('no_claim', 'полосы нет — itd.claim(метка)')

  const claim = (label: string): ClaimState | ClaimRefusal => {
    const bad = checkLabel(label)
    if (bad) return bad
    // Повторный вызов меняет только метку: счёт сбрасывает stop() → claim()
    if (rec) rec.label = label
    else {
      rec = newRecord(label, sha, Date.now())
      install()
    }
    paint()
    save()
    return stateOf(rec, Date.now(), true)
  }

  const mine = (n: number = 1, ms: number = MINE_DEFAULT_MS): ClaimMine | ClaimRefusal => {
    if (!rec) return noClaim()
    const bad = checkMine(n, ms)
    if (bad) return bad
    setMine(rec, n, ms, Date.now())
    save()
    return { ok: true, pending: n, ms }
  }

  const allow = (what: string, opts?: { target?: string }): ClaimState | ClaimRefusal => {
    if (!rec) return noClaim()
    const target = opts?.target
    const bad = checkAllow(what, target)
    if (bad) return bad
    openAllow(rec, what, target, Date.now())
    paint()
    save()
    return stateOf(rec, Date.now(), true)
  }

  const deny = (): ClaimAllowResult | ClaimRefusal => {
    if (!rec) return noClaim()
    const res = closeAllow(rec)
    paint()
    save()
    return res
  }

  const state = (): ClaimState | { ok: true; active: false } =>
    rec ? stateOf(rec, Date.now(), true) : { ok: true, active: false }

  const stop = (): ClaimState | ClaimRefusal => {
    if (!rec) return noClaim()
    const fin = stateOf(rec, Date.now(), false)
    uninstall()
    rec = null
    sessionStore.remove(CLAIM_KEY)
    document.title = TITLE_FREE
    return fin
  }

  // F5: запись вкладки поднимает полосу сразу, не дожидаясь READY Phaser
  const saved = parseRecord(sessionStore.get(CLAIM_KEY))
  if (saved) {
    rec = saved
    rec.reloads += 1
    rec.sha = sha // JS вкладки после перезагрузки — может быть уже другая сборка
    if (rec.mine && Date.now() >= rec.mine.until) rec.mine = null
    install()
    save()
  }

  return Object.assign(claim, { mine, allow, deny, state, stop })
}
```
