# Итерация 15 — сотрудники 2.0: увольнение, опыт/уровни, звёзды, менторство (дизайн)

Дата: 2026-08-27. Задача ITGAME-7. Статус: утверждён (автономный прогон).

## Проблема

Геймдизайн-ревью 2026-08-26 (п. 5): сотрудники — статичные фигурки.
Ролл $9–14 при найме навсегда, каждый найм — чистая арифметика. Нет
ни увольнения (неудачный ролл — вечная обуза), ни прокачки (длинный
штат — только ФОТ), ни рулеточности найма.

## Решение — четыре механики (первый срез, без типов сотрудников)

### 1. Увольнение

Правый клик по сотруднику в офисе → модалка подтверждения
«Уволить за $N?» → команда `fire`. Эффекты:

- ПК **остаётся** в офисе (счётчик PCs не меняется) — свободен для
  нового найма без покупки;
- сотрудник уходит вместе с опытом, уровнем и «звездой» — новый найм
  начинается с нуля;
- **компенсация $250** (однодневная зарплата); нанятый в тот же
  игровой день — **$100** («испытательный срок»).

Анти-эксплойт-арифметика (проверена, см. GDD «Сотрудники 2.0»):
переролл выработки = $300 + $100 = $400 за EV +$43/день — строго хуже
нового места (+$302/день); «вечерний найм» (после 15:00 без зарплаты)
с увольнением до конца дня убыточен (~$276 дохода против $400).
Переролл до звезды (~$8k) — осознанный поздний sink.

### 2. Опыт и уровни

- **2 XP за продуктивный тик**: не обед, ПК не сломан (дебаффы/вирус
  не мешают — работа есть работа). В обед и на сломанном ПК опыта нет.
- Уровни по накопленному XP: **96 / 288 / 576** (≈1/3/6 дней), потолок
  **уровень 3**; на потолке опыт не копится.
- Прибавка к личной выработке **до эффектов и сетевого множителя**:
  уровень 1 → **+$1/тик**, 2 → **+$2/тик**, 3 → **+$2/тик**. Ветеран
  6 дней ≈ +17% выработки бесплатно; прибавка множится сетью — тенюра
  и инфраструктура усиливают друг друга.

### 3. Звёзды (рулеточность найма)

- При **обычном найме** шанс **5%**: ролл выработки ×1.5 (округление
  до целого), имя получает суффикс « ★», в снапшоте `star: true`,
  в офисе — золотой бейдж. **Зарплата обычная** — звезда просто лучше.
- Звёздный кандидат (событие итерации 10) — тот же концепт: тоже
  `star: true` и бейдж, но выработка $20 фиксированно и зарплата ×2.

### 4. Менторство начальника

Пока начальник нанят в офисе (`Boss != ""`), его сотрудники копят
**3 XP/тик (×1.5)**: уровень 3 за 4 дня вместо 6. Босс — не только
«плата за слоты 10–12».

## Числа (источник истины — GDD, потом config.go)

| Параметр | Значение |
|---|---|
| XP за продуктивный тик | 2 (3 при начальнике в офисе) |
| Пороги уровней (XP всего) | 96 / 288 / 576 |
| Прибавка уровня к выработке | +$1 / +$2 / +$2 за тик |
| Шанс звезды при найме | 5% |
| Множитель выработки звезды | ×1.5 (на ролл, с округлением) |
| Компенсация увольнения | $250 ($100 в день найма) |

Сложность не скалирует эти числа (как сетевые множители) — ITGAME-9.

## Техническая схема

**Домен (`server/internal/game`):**
- `Employee`: поля `Star bool`, `HireDay int`, `XP int`. Уровень —
  производный от XP (чистая функция `levelFor`), не хранится.
- `Config`: `XPPerTick`, `XPMentorPerTick`, `EmployeeLevelXP []int`,
  `EmployeeLevelBonus []int`, `StarChancePct`, `StarMult`,
  `FireCompensation`, `FireCompSameDay`.
- `Hire`: ролл звезды до выработки (star-флаг → выработка ×1.5);
  `HireDay = g.Day`.
- `Fire(office, slot)`: валидация → компенсация → удаление из слайса.
  ПК остаются. Ретаргет событий повышения (active + pending): увольнение
  адресата резолвит событие, увольнение более позднего слота сдвигает
  индекс.
- `Tick()`: после дохода тика (не в обед) — `accrueXP()`: +2/+3 всем
  сотрудникам с целым ПК ниже потолка. Прогноз конца дня XP не
  трогает (снапшот-чистые функции).
- Формула дохода: `(IncomePerTick + levelBonus) × эффекты × сеть`.

**Протокол (protocol.go ⇄ protocol.ts синхронно):**
- Команда: `fire` — `{office, slot}`.
- `employeeInfo`: `level int`, `xp int`, `xpNext int` (0 на потолке),
  `star bool`, `firePrice int` (компенсация этого сотрудника).
- Ошибки: существующие `bad_slot`, `not_enough_money`.

**Клиент:**
- Правый клик по сотруднику → модалка «Уволить» (имя, уровень,
  компенсация, что теряется) → `fire`. Контекстное меню браузера
  отключается (`disableContextMenu`).
- Тултип: строка уровня «ур. N (+$B/тик), опыт E/T» или «опыт MAX»,
  «★ звезда ×1.5», подсказка «правый клик — уволить».
- Золотой ★-бейдж над звёздами (в т.ч. кандидатом события).
- Левый клик по сотруднику остаётся мотивацией.

## Тесты

- Увольнение: освобождает ПК (найм после без buy_pc), компенсация
  $100 в день найма / $250 на следующий день, `not_enough_money`,
  `bad_slot`, опыт нового — с нуля, сеть пересчитывается (первым N).
- Увольнение + событие повышения: адресат уволен — событие
  авто-резолвится; уволен следующий за адресатом — индекс сдвигается.
- XP: 2/тик, в обед нет, на сломанном ПК нет, с боссом 3/тик,
  на потолке не копится; уровни на 96/288/576; доход растёт с уровнем
  ((база+бонус)×сеть).
- Звезда: `StarChancePct=100/0` — детерминированные границы; seeded
  rng — 2000 роллов найма/увольнения, доля звёзд в допуске 5%±1.5;
  выработка звезды = round(ролл×1.5).
- Протокол: снапшот несёт level/xp/xpNext/star/firePrice; `fire`
  end-to-end (ws-тест по образцу session_test).
