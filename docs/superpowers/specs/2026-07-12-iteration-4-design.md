# Итерация 4 — три офиса, начальники, шлюз, неполный день (дизайн)

Дата: 2026-07-12. Статус: одобрен пользователем (брейншторм в сессии).

## Контекст и цель

Плейтест итерации 3 зачтён; заявки игрока: три офиса с левой панелью
навигации, начальник (открывает слоты 10–12), шлюз в интернет,
зарплата за неполный день. Взято ВСЁ (решение игрока). Цель — дать игре
середину и позднюю стадию: путь до потолка через покупку и раскрутку
офисов 2–3.

## 1. Домен: офисы списком (`internal/game`)

- `type Office struct { Unlocked bool; PCs int; Employees []Employee;
  RouterTier int; Boss string }` — босс: имя из генератора, `""` = нет.
- `Game.Offices []Office` (длина 3). Поля `PCs/Employees/RouterTier`
  уезжают из `Game` в `Office`. Старт: офис 0 — `Unlocked: true, PCs: 1`;
  офисы 1–2 закрыты. Серверная общая: `Game.Servers int`,
  `Game.Gateway bool`.
- **Подключение** по-офисно: `office.Connected() = min(портыРоутераОфиса,
  len(office.Employees))`.
- **Множитель** общий на компанию:
  `база = 1.0 + 0.5×Servers` (для офиса без роутера — 1.0, серверы не
  достаются); **шлюз**: ещё `×1.2` подключённым (итог для подключённого:
  `выработка × (1.0+0.5×S) × (Gateway ? 1.2 : 1.0)`, округление на
  сотрудника как раньше).
- **Доход** = Σ по открытым офисам. Часы/обед/день — общие (без изменений).

## 2. Начальник

- Специальный слот в каждом офисе (аналог слота роутера).
- `HireBoss(office)`: цена **$1,000** (`BossPrice`), имя роллится
  генератором; выработки НЕТ — чистый оверхед.
- Зарплата **$500/день** (`BossSalaryPerDay`), входит в ФОТ.
- Эффект: слоты 10–12 СВОЕГО офиса открываются (`StaffLimit` 9 → 12 для
  офиса с боссом; константа `OfficeSlots=12` без изменений).
- Ошибки: `staff_limit` остаётся (офис без босса, 10-й ПК/найм) — текст
  тоста: «Наймите начальника — он откроет ещё 3 места»; `boss_already`
  (босс уже есть); `office_locked` (операция в закрытом офисе).

## 3. Покупка офисов и шлюз

- `BuyOffice`: офис 2 — **$15,000**, офис 3 — **$40,000**
  (`OfficePrices []int`), строго последовательно (`offices_maxed`, если
  всё куплено; покупать можно только следующий закрытый). Открывается
  пустым: 0 ПК, без роутера, без босса.
- `BuyGateway`: **$3,000** (`GatewayPrice`), один на компанию
  (`gateway_already`). Эффект ×1.2 подключённым (см. §1).
- **Опекс шлюза**: **$1/день** (`GatewayOpexPerDay`) — списывается в
  конце дня вместе с зарплатами; в `day_report` отдельное поле.

## 4. Зарплата за неполный день

- `Employee` получает флаг `UnpaidToday bool`: ставится при найме с
  тика ≥ конца обеда (время ≥ 15:00, `LunchEnd`); в ФОТ текущего дня
  такой сотрудник не входит. `NextDay()` сбрасывает флаги.
- Граница: найм в 14:59 — платим полный день; в 15:00 — не платим.
- Касается и начальника (у офиса флаг `BossUnpaidToday bool` — или босс
  становится `Employee` с нулевой выработкой; решить в плане, интерфейс
  протокола от этого не зависит).
- Тултип сотрудника с флагом: строка «сегодня без оплаты».

## 5. Протокол (ломающие изменения)

- Команды получают адресата-офис: клиентское сообщение
  `{"type": "...", "office": N}` (N = индекс 0–2). Офисные команды:
  `buy_pc`, `hire`, `buy_router`, `hire_boss`, `buy_office`
  (office = какой покупаем). Команды без офиса: `buy_server`,
  `buy_gateway`, `next_day`, `restart`.
- Новые коды ошибок: `office_locked`, `boss_already`, `offices_maxed`,
  `gateway_already`, `bad_office` (индекс вне 0–2).
- Снапшот:
  - `offices: [{unlocked, price, pcs, routerTier, ports, boss,
    bossUnpaidToday, employees: [{name, incomePerTick, connected,
    unpaidToday}]}]` — `price` = цена покупки (0 для открытых);
    `nextRouter` переезжает внутрь офиса (`prices.nextRouter` удаляется).
  - Общие: `servers`, `gateway`, `multiplier` (серверная база),
    `incomePerTick`, `payrollPerDay` (сотрудники + боссы + опекс шлюза),
    `forecastEndOfDay`, `clock`, `isLunch`, `ticksPerHour`,
    `salaryPerDay`, `bossSalaryPerDay`, `staffLimit`, `day`, `phase`,
    `money`, `rackSlots`, `prices: {pc, hire, server, boss, gateway}`.
  - УДАЛЯЮТСЯ: `dayTicks`, `dayProgress` (клиент их не читает — часы
    заменили; YAGNI), плоские `pcs/routerTier/ports/employees/officeSlots`.
- `day_report` += `gatewayOpex` (int, 0 если шлюза нет); `payroll`
  включает боссов.
- `scripts/live-check.mjs` переписывается под новый снапшот (проверка
  offices-массива, покупки офиса не хватит денег → error, шлюз).

## 6. Клиент: левая панель навигации

- **Панель слева** (~64px): вертикальные значки Офис 1 / Офис 2 /
  Офис 3 / Серверная. Активная комната подсвечена рамкой; закрытый
  офис — серый с ценой под значком. Кнопка «В серверную» из HUD
  удаляется. Игровое поле комнат начинается после панели (сдвиг
  контента вправо, константа в layout.ts).
- Клик по закрытому офису: сцена офиса с оверлеем «Купить офис —
  $15,000» и кнопкой покупки (команда `buy_office`).
- HUD-подпись «Зарплата $N/день» меняется на «Расходы $N/день» —
  `payrollPerDay` теперь включает боссов и опекс шлюза.
- HUD-кнопки: ПК / Нанять / Роутер / **Начальник $1,000** — действуют
  на активный офис (клиент помнит `activeOffice`, шлёт в команде);
  Сервер / **Шлюз $3,000** — общие. Если активна серверная — офисные
  кнопки шлют в последний активный офис (поведение как раньше:
  сервер — источник истины, ошибки тостами).
- Сцена офиса параметризуется индексом активного офиса (одна сцена,
  перерисовка по данным `offices[active]`). Слот начальника рисуется
  рядом со слотом роутера: пустой («нет начальника») / занятый
  (спрайт + имя, тултип: имя, «Начальник», зарплата).
- Серверная: слот шлюза рядом со стойками (пустой/куплен).

## 7. Экономика

| Параметр            | Значение   | Комментарий                        |
|---------------------|------------|-------------------------------------|
| Начальник: найм     | $1,000     | не производит                       |
| Начальник: зарплата | $500/день  | ФОТ                                 |
| Офис 2              | $15,000    | пустой                              |
| Офис 3              | $40,000    | пустой, только после офиса 2        |
| Шлюз: покупка       | $3,000     | один на компанию                    |
| Шлюз: опекс         | $1/день    | списывается с ФОТ                   |
| Шлюз: эффект        | ×1.2       | только подключённым, поверх серверов |

Потолок: 36 сотрудников × ~$11.5 × 2.5 × 1.2 ≈ $1,240/тик
(≈$59,600/день при ФОТ $10,501/день). Все числа стартовые — крутим
по плейтесту.

## 8. Тесты

- Домен: по-офисный доход (офис без роутера не получает серверы; шлюз
  только подключённым); гейты BuyOffice (последовательность, деньги,
  offices_maxed); HireBoss (boss_already, staff_limit 9→12 только со
  своим боссом); опекс шлюза в конце дня и в отчёте; неполный день
  (границы 14:59/15:00, сброс на next_day, босс); Restart сбрасывает
  офисы; миграция существующих тестов на Offices[0].
- ws: снапшот offices-массива; команды с адресатом (bad_office,
  office_locked); интеграционный цикл дня с боссом и шлюзом в ФОТ.
- Клиент: typecheck; браузерный смоук (панель, покупка офиса, босс,
  шлюз, «сегодня без оплаты»); live-check вживую.

## Вне скоупа

Роутер тир 3, переезд сотрудников между офисами, увольнение,
индивидуальные зарплаты, события, персистентность, графика.

## Критерий готовности

Плейтест: покупка офиса 2 ощущается как большое решение; начальник —
осмысленный расчёт, а не автопокупка; шлюз заметен в цифрах; путь до
потолка ощутимо длиннее итерации 3 и не проседает по интересу в середине.
