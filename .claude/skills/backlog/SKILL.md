# /backlog — что брать дальше

Ответ — **решение**: 2-3 кандидата, у каждого одна строка «почему сейчас и что это закрывает
или разблокирует». Список из шестидесяти строк, возвращенный обратно, разбором не является.

Аргументы: `$ARGUMENTS`. Первое слово — охват: `open` (по умолчанию), `backlog` или `todo`,
всё прочее переспроси, а не сужай молча. Второе слово — scratch-доска: тогда чтение получает
`.in(<slug>)`. Без него читаешь СВОЮ доску.

## 1. Прочитать — один вызов

```
board.backlog
```

Один ответ, пять конвертов: open (backlog+todo, `pri desc`), waiting, blocked (по ФЛАГУ blocked,
с блокерами), constraint, sys.wip. Полнота читается с самого ответа: `more:0` на секции значит
секция целиком — сверки с count больше нет. `more:1` бывает только у доски шире 1000 строк:
тогда дочиитай хвост `task.where(state = open)...skip(<пришло>)`.

Непонятное поле — `help task`, не угадывай.

Охват `backlog` или `todo` — не отдельный вызов: у секции open есть колонка status, фильтруй
её по значению. Смысла narrower нет: waiting и blocked нужны любому охвату.

## 2. Отделить до рекомендаций

- **Заблокированные** (секция blocked) — не кандидаты. Кто блокирует — уже в секции.
- **`needs-input`** и **waiting** ждут человека или срока, а не тебя. Перечисли коротко.
- **Ограничения.** Пустой конверт constraint значит, что на доске их нет. Для ОДНОГО кандидата
  проще одним вызовом `task.context.where(code=X)` — конверт constraints там уже собран (проект,
  теги, сама задача), не гадать отдельным `constraint.where(code=X)`. `deny` значит «прочитай
  правило до действия», а не «задача запрещена». `enforcedBy: agent` — проверяешь ты.
- **WIP.** Конверт sys.wip скажет, есть ли свободный слот. Без слота рекомендация звучит как
  «следующей, когда освободится X».

## 3. Выбрать 2-3 кандидата

Прочитай детали только у тех, кого рекомендуешь, и у подозрительных на протухание:

```
task.where(code in (…)).select(code, activity, summary(body), summary(log), dependents, related).take(10).budget(40000)
```

`where` не больше чем на 10 точных кодов (`=` или `in (…)`) обходится без `take`: код называет
ровно одну задачу во всём трекере, так что страница уже ограничена числом кодов, а `~` рядом с
ними лишь дофильтровывает то, что коды уже разрешили. На большем наборе или с одним только
шаблоном `~` (без точных кодов) `take(10)` (или меньше) обязателен, иначе страница с `summary(…)`
отказывает `!Evalue`. `summary(…)` — пересказ, в нём бывают ошибки. Перед тем как утверждать
факт о задаче, полный текст берёшь через `select(body)` или `log.where(code=X)` — а если нужен
весь расклад по ОДНОЙ задаче (паспорт, лог, живые блокеры, ограничения), проще один вызов
`task.context.where(code=X)`, чем собирать то же самое по кускам. Страницу на 2-3 кандидата
(`task.where(code in (…))...`) он не заменяет — это разные вызовы для разных вопросов.

Предпочитай задачи, которые что-то закрывают или разблокируют (`dependents`), дёшевы (`est` 1–3)
при высоком весе или бьют по проблеме, всплывшей в этой же сессии. Если обоснование не влезает
в строку, задачу стоит дробить — так и скажи.

Строка open с `prefers_worker = true` — подсказка «лучше воркеру»: помечай такого кандидата
«лучше воркеру» и ставь его после равных ему по весу задач для интерактивной сессии. Взять её
никто не запрещает — это подсказка, не запрет.

## 4. Протухшее — назвать и спросить

Ничего не закрывай и не перестатусивай сам. Ищи:

- задачу, чью посылку изменила уже закрытая задача: тело спорит с тем, что есть в коде или в
  AGENTS.md сейчас. Проверь по коду или `git log --grep=<код>`, а не по пересказу;
- исправление уже применено, осталась только приёмка владельца — место такой задачи в `waiting`;
- задачу, которая по тексту «не начинать раньше X», при этом без блокера на X;
- пары задач, пересекающихся по сути;
- `activity` давно не двигалась, а тело ссылается на обстановку, которой нет.

## Форма ответа

Первой строкой — вердикт: какие коды брать. Дальше короткие списки: кандидаты с обоснованием,
high-приоритет не сейчас и почему, ждут человека, протухшее с вопросом. Цифры объёма доски —
одной строкой (они теперь видны из конвертов: строки секций + `used:` из wip). Таблицу на всю
доску не выводи.
